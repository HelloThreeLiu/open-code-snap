# Open Code Snap 产品需求文档（PRD）

> 版本：v1.0 · 2026-11-04
> 状态：已定稿（里程碑内容随 roadmap 滚动更新）

## 1. 产品定位

一句话：**在 IDE 里选中代码，一键生成可直接分享的精美代码图片。**

- 目标用户：写技术文章/推文/文档/PPT 的开发者
- 核心场景：VS Code 中选中代码 → 右键/命令打开面板 → 实时预览 → 复制到剪贴板或保存 PNG
- 差异化定位：活跃维护、MIT、高亮与编辑器一致、导出快且所见即所得、可深度自定义

## 2. 非目标（明确不做）

- 不做代码编辑器（面板只预览，不编辑）
- 不做后端服务（无账号、无分享服务器，纯本地）
- 不做屏幕截图/区域截屏（只处理代码文本）

## 4. 功能需求

### 4.1 M1 — MVP（可用即发布）

**F1 代码输入与同步**
- F1.1 命令 `Open Code Snap`（命令面板 / 编辑器右键菜单 / 快捷键）打开预览面板
- F1.2 活动编辑器选区变化 → 面板实时更新（防抖 ≤150ms）
- F1.3 **禁止**通过剪贴板取内容（不得覆盖用户剪贴板）
- F1.4 语言自动识别（`document.languageId`），可手动覆盖
- 验收：多文件/多编辑器切换时内容正确跟随；选区为空时显示占位提示

**F2 渲染与样式**
- F2.1 Shiki 高亮，跟随 `workbench.colorTheme`（名称映射到内置主题，映射失败回退默认并在 UI 提示），可下拉切换内置主题
- F2.2 窗口样式：macOS 交通灯 / Windows 按钮 / 无；窗口标题（文件名，可编辑）；可整体隐藏
- F2.3 行号：关闭 / 相对 / 真实行号（按选区起始行）
- F2.4 背景：纯色 + 透明；内边距、圆角、阴影（颜色/模糊/偏移）参数化
- F2.5 字体：默认跟随 `editor.fontFamily`，可自定义；字号、行高、Tab 宽度、连字开关
- 验收：与编辑器同主题下高亮颜色一致（spot check 5 种主流主题）；等宽对齐无错位

**F3 导出**
- F3.1 PNG 导出，缩放 1x/2x/3x
- F3.2 保存到文件（记住上次目录）+ 复制到剪贴板
- F3.3 导出引擎：Canvas 自绘（M0 实测验证，唯一引擎；dom-to-image 兜底引擎因 300 行 11.7s 不可用，已于 0.3.0 移除，见 tech-design ADR D7）；面板显示本次导出耗时
- 验收：300 行代码导出 < 500ms（Canvas 路径，M0 实测数据校准）；导出图与预览像素级一致（抽查）

**F4 设置**
- F4.1 全部样式项进 VS Code `settings.json`（`openCodeSnap.*`）
- F4.2 面板内改动即时写回用户设置

### 4.2 M2 — Beta

- F5 渐变背景（双色，角度可调）；网格/点阵背景
- F6 水印：文字（含模板变量 `{date}` `{file}`）、字号、透明度、位置（四角/平铺）
- F7 行高亮 diff：点击行号循环 普通 → 新增(+) → 删除(−)，导出同步染色
- F8 SVG 矢量导出（自绘路线直接产出）
- F9 预设：命名保存多套配置，导出/导入 JSON（语义：预设为「所见即所存」快照——编辑器派生值（字体/连字跟随回填后的结果）在保存时冻结，不保留「留空跟随」；文档相关的 tabSize 不进预设）

### 4.3 M3 — 1.0

- F10 脱敏遮罩：选中连续文本 → 马赛克/替换为 `***`，导出同步生效
  - 决策：交互 = 预览中选中文本 → 工具栏「打码」→ 遮罩生成；点击遮罩恢复。遮罩为会话级状态（代码变化即清空，与 F7 行标记同语义），不进预设内容（预设仅含 `maskStyle` 样式键）。
  - 决策：不做真马赛克/模糊——canvas 与 DOM 两路径难以像素级一致；采用确定性几何：`block` 色块（默认）/ `asterisk` 等宽星号（`maskStyle` 配置，星号数量按原文本实测宽度对齐，CJK 不错位）。
  - 决策：SVG 导出中被遮文本必须**替换**而非覆盖（SVG 源码不可还原原文，安全要求）；PNG 为位图天然无此问题。
  - 决策：遮罩重叠时归一化合并为不相交区间，点击整体移除（换取渲染与命中测试的简单性）。
- F11 长代码优化（>1000 行分片提示与性能保障）
- F12 界面 i18n（中/英）
- F13 发布 marketplace + GitHub Actions 自动化（lint/test/发版）

## 5. 性能预算

| 指标 | 目标 |
|---|---|
| 选区变化 → 预览更新 | < 100ms（100 行内） |
| 导出 300 行 PNG（Canvas） | < 500ms |
| 导出内存峰值 | 无 dom-to-image 式巨型字符串峰值 |
| 面板冷启动 | < 1s（含 Shiki 懒加载首个语言） |

## 6. 兼性与环境

- VS Code ≥ 1.80（桌面版 + Remote SSH/WSL/Dev Container；vscode.dev Web 版为尽力支持，不阻塞发布）
- 平台：Windows / macOS / Linux
